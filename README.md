A modern iOS travel booking application built with **SwiftUI**, **Combine** for reactive state management, and clean **MVVM** architecture.

## Key Highlights
- **Architecture:** Feature-first modular MVVM with reactive Combine pipelines and type-safe `NavigationRouter`.
- **UI & UX:** Custom reusable SwiftUI components, dynamic bottom sheets, and responsive layouts.
- **CI/CD:** Automated build and test verification via GitHub Actions on every push and pull request.
